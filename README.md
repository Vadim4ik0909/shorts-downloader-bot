# Telegram Bot Downloader (YouTube Shorts, TikTok, Instagram)

Сучасний асинхронний Telegram-бот на базі **aiogram 3**, **yt-dlp** та **FFmpeg**, створений для завантаження:
- 🎬 **YouTube Shorts**
- 📱 **TikTok** (відео без водяного знака, повні **фото-слайдшоу** + оригінальний трек)
- 📸 **Instagram** (Reels, пости та **каруселі фото/відео**)
- 🐦 **Twitter (X)**, Pinterest, Reddit тощо.

---

## 🚀 Реалізовані покращення

1. ⚡️ **Миттєве кешування (`file_id` в SQLite)**:
   - Після першого завантаження Telegram-ідентифікатор медіа зберігається в базі даних.
   - Повторні запити того ж відео/фото надсилаються **миттєво за 0.1–0.2 с** без повторного скачування та витрати трафіку!
   - Посилання автоматично нормалізуються (видаляються параметри на зразок `?feature=share`, `?si=...`).
2. 🗜 **Автоматичне стиснення відео через FFmpeg**:
   - Якщо відео перевищує ліміт Telegram (50 МБ), бот не відхиляє його, а автоматично розраховує бітрейт і стискає файл до ~45 МБ з оптимізацією для мобільного стрімінгу (`+faststart`).
3. 🔄 **Черга завантажень (Async Queue)**:
   - Обмежує кількість одночасних важких завантажень (до 3 одночасно), щоб не перевантажувати процесор та інтернет.
   - Якщо черга заповнена, користувач бачить свою позицію: `⏳ Ви в черзі на завантаження (позиція: 2)...`.
4. 📊 **Живий прогрес-бар (Live Progress Bar)**:
   - Під час завантаження відео в чаті відображається плавний прогрес:
     `⏳ Завантаження: [▓▓▓▓▓░░░░░] 52% (8.4 МБ / 16.1 МБ) • ~2.4 МБ/с`
5. 🌐 **Inline Mode (Інлайн-режим)**:
   - Можна користуватися ботом у будь-якому чаті чи групі: напишіть `@shorts_METIOS_bot https://...` і відправляйте збережені медіа прямо співрозмовникам.

## ⚙️ Як увімкнути Inline Mode у @BotFather

Щоб інлайн-режим запрацював у Telegram:
1. Відкрийте [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/setinline`.
3. Оберіть вашого бота: `@shorts_METIOS_bot`.
4. Введіть плейсхолдер (наприклад: `Вставте посилання на Shorts/TikTok/Reels...`).
5. Готово! Тепер ви можете викликати бота в будь-якому чаті через `@shorts_METIOS_bot <посилання>`.
